# 🌙 悠悠自習室

線上多人的「專注小屋」:你就在一間封閉的溫馨房間裡,窗外有風景,角色坐在書桌前陪你專注。佈置房間、換角色造型、開番茄鐘,朋友可以用邀請連結進來一起自習。

## 功能

- **室內視角**:鏡頭在房間裡面,有桌前、全景、側面三種視角與自動運鏡;拖曳可環顧四周,滾輪或雙指縮放。介面是可收合的小卡片,專注時只留時間
- **柔光效果**:燈、螢幕、霓虹燈會發光暈開(可在設定關閉)
- **專注計時**:番茄鐘(專注與休息自動循環)、倒數、正計時;開始後角色會走到椅子坐下打字、看書或寫字,休息時站起來。計時在伺服器端,中途斷線回來仍會結算
- **走路會繞過家具**:點地板移動時自動找路;書桌椅子坐滿了,其他人會去坐沙發(每張兩人)
- **切到別的分頁也能用**:分頁標題會繼續倒數,時間到會跳系統通知(第一次開始專注時詢問是否允許)
- **雨聲與窗外連動**:開著雨聲時,窗外變陰天並下雨
- **自動畫質**:畫面卡頓時自動調低解析度、柔光和陰影,也可以在設定手動選
- **會走動的貓**:貓會在家附近閒晃、繞過家具,走一走就趴下休息
- **拍照**:隨時照目前的鏡頭拍一張帶名字的照片並下載
- **表情動作**:按 👋 角色會揮手,其他表情會笑一下
- **狀態與待辦**:頭上顯示「正在做什麼」;待辦清單跟著雲端存檔
- **每日習慣**:每天打卡,顯示近 7 天紀錄與連續天數
- **專注統計**:今天、本週、連續天數、累計,以及近 7 天/近 30 天的每日專注分鐘圖表(依你當地的日期計算)
- **共同專注**:房主發起後,房間裡的人可以加入,大家同時開始、同時結束,完成後自動拍一張合照
- **多人同房間**:每個人有自己的房間與 6 碼房號,分享邀請連結即可即時看到彼此(每房最多 12 人)
- **房間佈置**:50 種原創家具分成八類(桌椅、收納、床與沙發、電器、植物燈飾、桌上小物、牆面、地毯),全部直接可用;小物可以放在桌面、矮櫃和床上,位置以四分之一格為單位,同一張桌子能擺好幾件;大多數可換 8 種顏色(佈置時按 C);椅子會自動朝向旁邊的桌子;房主可開放朋友一起佈置
- **角色自訂**:12 個造型可選:6 個動漫風角色,加上 6 個早期的積木風角色。髮色、瞳色、上衣、下身都可以從色票選或自己挑任意顏色;頭的大小可調(調大就是 Q 版比例)、身高可調、平常的表情可選(自然/微笑/放鬆)、5 種膚色;還能戴頭飾(耳機、貓耳、貝雷帽)和眼鏡,頭飾可換色。角色會眨眼、看鏡頭,頭髮和衣服會擺動
- **成品房間與旋轉**:書房、臥室、客廳三組現成擺設可一鍵套用;家具可旋轉(佈置時按 R)
- **日夜光線**:白天、黃昏、夜晚,預設依你當地時間自動切換
- **表情與聊天**:表情符號為主,另有文字對話
- **雲端存檔**:進度存在伺服器,用「存檔碼」可在其他裝置接續
- **本機備份自動還原**:進度同時在瀏覽器留一份;伺服器的資料不見時(例如免費主機重啟),同一台裝置回來會自動還原,房號也會換回原本的
- **音樂播放**:10 首 lo-fi 曲目,有播放/暫停、上下一首、隨機、進度與音量;可以加入自己裝置上的音樂檔(只在本機播放,不會上傳);每個人各自播放,不會互相影響
- **環境音**:雨聲、白噪音(瀏覽器即時合成),可以和音樂疊在一起

## 執行

需要 Node.js 18 以上,以及支援 WebGL 的瀏覽器。

```bash
npm install
npm start
# 打開 http://localhost:3000
```

環境變數:

| 變數 | 預設 | 說明 |
| --- | --- | --- |
| `PORT` | `3000` | 監聽埠 |
| `DATA_DIR` | `./data` | 存檔位置(`profiles.json`、`rooms.json`) |

## 部署

這是一個單一 Node 行程(HTTP + WebSocket),可部署到任何支援 WebSocket 的平台(Render、Railway、Fly.io、自己的 VPS 等),啟動指令為 `npm start`。

倉庫附有 Render 的設定檔 `render.yaml`:在 Render 選「New > Blueprint」接上這個倉庫就能部署(免費方案閒置後會休眠,且存檔不會保留)。

存檔寫在 `DATA_DIR` 的 JSON 檔裡,部署時請把它指到**持久化磁碟**,否則重新部署後存檔會消失。純靜態主機(如 GitHub Pages)無法執行,因為需要伺服器。

## 結構

```
server.js          伺服器:靜態檔案、WebSocket 協定、驗證與存檔
public/index.html  頁面
public/style.css   樣式
public/game.js     3D 場景(three.js)、連線、計時、佈置、聊天、環境音
```
